# NOVA Sales Intelligence

Interactive electronics sales analytics dashboard built with Streamlit, Pandas, and Plotly.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Deploy this repository with Streamlit Community Cloud and set the main file path to `app.py`.

The app can load CSV files from a `data/` folder in the repository, or accept a CSV/ZIP upload in the sidebar. The included sales data, if added, should be synthetic/demo data only—do not commit private customer or business data.
